# Hermes Skills

A collection of agent skills created by Hermes, compatible with `npx skills`.

## Available Skills

### notion-style-frontend

Notion-style design and layout guidelines for frontend development.

**Use when:**
- Writing frontend pages or UI components
- Building web apps, admin dashboards, or documentation tools
- Need a clean, minimal, block-based interface style

**Covers:**
- Color tokens (Notion's signature gray palette)
- Typography and spacing
- Layout and page structure (sidebar, page tree, content canvas)
- Component styles (buttons, inputs, callouts, dropdowns)
- Radius, shadows, and interactions
- Responsive behavior and loading states

## Installation

```bash
npx skills add QinYangWang/hermes-skills
```
